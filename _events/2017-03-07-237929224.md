This month's guest speakers are Beverley Gibas and Robert Giggey from the City of Ottawa who will be introducing a new Open311 Web Services Pilot to the Ottawa Civic Tech community:
To support the City of Ottawa’s Strategic Objective to improve access to City services through digital service delivery, the City is launching an application program interface (API) that will allow the external community to develop applications that can submit Service Requests directly to the City as well as to consume data regarding these Service Requests. Information sent through the API will integrate with the existing Citizen Service Management (CSM) application without agent intervention. The API will allow developers to integrate features into existing apps, or be used in the development of new applications. A pilot approach is being used to evaluate uptake from the community and inform next steps for the City.
